# Fonts bundled for Open Graph image generation

Static instances of **Playfair Display** (Bold 700 and Medium Italic 500),
downloaded from Google Fonts and committed so that `ImageResponse` (satori)
can embed them without a network request at build time — satori cannot use
the variable fonts that `next/font` self-hosts for the pages.
